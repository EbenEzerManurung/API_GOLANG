# \## Tech Stack

# 

# \- \*\*Golang\*\* - API Server (Gin/Echo/Net/http - adjust as needed)

# \- \*\*MySQL\*\* - Relational Database

# \- \*\*REST API\*\* - Backend-frontend communication

# \- \*\*JWT\*\* - Authentication \& Authorization

# 

# \## Prerequisites

# 

# Before running this project, make sure you have installed:

# 

# \- \[Go](https://go.dev/dl/) (version 1.20 or newer)

# \- \[MySQL](https://dev.mysql.com/downloads/) (version 8.0+)

# \- \[Git](https://git-scm.com/)

# 

# \# 1. Clone repository

# git clone https://github.com/EbenEzerManurung/API\_GOLANG.git

# cd API\_GOLANG

# 

# \# 2. Install dependencies

# go get github.com/go-sql-driver/mysql

# 

# \# 3. Jalankan seeder

# go run seeder/all\_seeder.go
